# Monitoreo de Calidad del Agua mediante Sensores IoT

## Descripción del Proyecto
Este sistema en C++ simula una red de sensores IoT para el monitoreo en tiempo real de la calidad del agua. El software aplica principios de Programación Orientada a Objetos (POO) como herencia, encapsulación y polimorfismo para estructurar el flujo de recolección, procesamiento, alertas y reportes de datos (pH, temperatura).

## Problema y Alineación con ODS 6
En muchas comunidades, la calidad del agua se revisa de forma manual y esporádica, lo que impide detectar a tiempo cambios peligrosos y retrasa la toma de decisiones. Este proyecto contribuye directamente al **ODS 6 (Agua limpia y saneamiento)**, apoyando la meta 6.1 (acceso a agua potable segura) y la meta 6.3 (reducción de la contaminación) mediante el monitoreo continuo y la prevención de riesgos.
