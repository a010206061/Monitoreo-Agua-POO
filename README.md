# Monitoreo de Calidad del Agua mediante Sensores IoT

## Descripción del Proyecto
Este sistema en C++ simula una red de sensores IoT para el monitoreo en tiempo real de la calidad del agua. El software aplica principios de Programación Orientada a Objetos (POO) como herencia, encapsulación y polimorfismo para estructurar el flujo de recolección, procesamiento, alertas y reportes de datos (pH, temperatura).

## Problema y Alineación con ODS 6
En muchas comunidades, la calidad del agua se revisa de forma manual y esporádica, lo que impide detectar a tiempo cambios peligrosos y retrasar la toma de decisiones. Este proyecto contribuye directamente al ODS 6 (Agua limpia y saneamiento), apoyando la meta 6.1 (acceso a agua potable segura) y la meta 6.3 (reducción de la contaminación) mediante el monitoreo continuo y la prevención de riesgos.

## Instrucciones de Ejecución
1. Clonar este repositorio en el equipo local usando la terminal: `git clone <URL_DEL_REPOSITORIO>`
2. Abrir la carpeta del proyecto en Visual Studio Code o abrir el archivo de solución (`.sln`) en Visual Studio.
3. Compilar el archivo de código fuente principal.
4. Ejecutar el programa para inicializar la estación de monitoreo, cargar los sensores de pH y Temperatura, y visualizar las lecturas y alertas de calidad del agua en la consola.
